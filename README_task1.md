### 1. 实验背景与数学建模

在实验 A 中，我们的目标是：仅使用一幅灰度图像 $S$（大小为 $H \times W$）的水平和垂直前向差分梯度场，以及其最外围的一圈边界像素值，来完美重建出原图像。

#### 1.1 梯度计算（前向差分）
设 $S(y, x) \in [0, 1]$ 为归一化后的输入灰度图。我们计算其前向差分梯度场：
- 水平梯度：$G_x(y, x) = S(y, x+1) - S(y, x)$，其中 $0 \le y < H, 0 \le x < W-1$。
- 垂直梯度：$G_y(y, x) = S(y+1, x) - S(y, x)$，其中 $0 \le y < H-1, 0 \le x < W$。

#### 1.2 坐标映射 (im2var)
图像是一个 $H \times W$ 的二维网格，我们需要将每个二维像素坐标 $(y, x)$ 映射到线性方程组中唯一的一维变量索引 $i \in [0, HW-1]$：
$$i = im2var(y, x) = y \times W + x$$
我们将重建后的目标图像表示为一个一维未知数向量 $v$（大小为 $HW \times 1$）。我们将构建并求解线性方程组 $A v = b$，其中 $A$ 是一个 $HW \times HW$ 的稀疏矩阵，$b$ 是一个 $HW \times 1$ 的右端项列向量。

#### 1.3 线性系统构建 (Av = b)
对于图像中的每一个像素 $p = (y, x)$，其对应的一维索引为 $i = im2var(y, x)$：

1. **边界像素（Dirichlet 边界条件）**
   如果像素 $p$ 位于图像的最外围一圈边界上（即 $y = 0$ 或 $y = H-1$ 或 $x = 0$ 或 $x = W-1$）：
   - 我们强制令重建值等于原图真实值：$v(y, x) = S(y, x)$。
   - 对应矩阵 $A$ 的第 $i$ 行：对角线元素 $A[i, i] = 1.0$，该行其他元素均为 0。
   - 对应右端项 $b$ 的第 $i$ 个元素：$b[i] = S(y, x)$。

2. **内部像素（离散泊松方程）**
   如果像素 $p$ 位于图像内部（即 $0 < y < H-1$ 且 $0 < x < W-1$）：
   - 我们要求重建图像的离散拉普拉斯算子等于梯度场的散度：
     $$4 v(y, x) - v(y-1, x) - v(y+1, x) - v(y, x-1) - v(y, x+1) = \text{div } \mathbf{G}(y, x)$$
   - 梯度场 $\mathbf{G} = (G_x, G_y)$ 在点 $(y, x)$ 处的离散散度采用后向差分计算：
     $$\text{div } \mathbf{G}(y, x) = G_x(y, x-1) - G_x(y, x) + G_y(y-1, x) - G_y(y, x)$$
   - 对应矩阵 $A$ 的第 $i$ 行：
     - 对角线项：$A[i, i] = 4.0$
     - 邻域项：$A[i, im2var(y-1, x)] = -1.0$
     - 邻域项：$A[i, im2var(y+1, x)] = -1.0$
     - 邻域项：$A[i, im2var(y, x-1)] = -1.0$
     - 邻域项：$A[i, im2var(y, x+1)] = -1.0$
   - 对应右端项 $b$ 的第 $i$ 个元素：
     - $b[i] = G_x(y, x-1) - G_x(y, x) + G_y(y-1, x) - G_y(y, x)$。

### 2. 高标准工程与编码要求

为了确保作业拿到满分，代码实现必须符合学术规范和高性能 Python 编程标准：
1. **像素归一化**：所有像素计算和矩阵操作必须使用 `float64` 进行，且输入图像必须提前归一化到 $[0.0, 1.0]$ 范围。
2. **高效稀疏矩阵组装**：严禁使用嵌套循环直接对 `lil_matrix` 或 `csr_matrix` 进行逐个元素的修改。必须先使用列表收集稀疏矩阵的三元组数据 `rows`、`cols` 和 `data`（即 COO 格式），然后一次性构建并转换为 CSR 格式：
   `A = sp.coo_matrix((data, (rows, cols)), shape=(HW, HW)).tocsr()`
3. **线性求解器**：使用高效的直接求解器 `scipy.sparse.linalg.spsolve` 来求解 $A v = b$。
4. **误差指标计算**：计算重建图像 $v$ 与原图 $S$ 之间的以下误差指标：
   - **均方误差 (MSE)**
   - **峰值信噪比 (PSNR)**（注意：由于图像已归一化，最大像素值 MAX 取 1.0）
   - **最大绝对误差 (Max Absolute Error)**
5. **可视化输出**：在 `results/` 文件夹下生成并保存以下三张对比图：
   - 原图 (Original Image)
   - 重建图 (Reconstructed Image)
   - 绝对误差图 (Absolute Error Map，即 $|S - v|$)
