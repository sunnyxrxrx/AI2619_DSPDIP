 Poisson Image Editing 核心方法复现与分析
一、项目说明
本项目为个人作业，围绕论文 Poisson Image Editing 展开。目标是复现论文中最核心的梯度域编辑方法：guided
interpolation、importing gradients 和 mixing gradients。
论文还包含 texture flattening、local illumination changes、local color changes 和 seamless tiling 等扩展工具，本作业不
要求完整复现这些扩展内容。

输入：poisson_toy_reconstruction.png。
●

●

实验 B：Core Reproduction: Seamless Cloning
●
输入：poisson_source.png、poisson_target.png、poisson_mask.png。
●
复现论文 importing gradients：在 mask 区域内使用 source 的梯度作为 guidance field，在 mask 边界处使用 target 像
素作为 Dirichlet boundary condition。
●
分别对 R、G、B 三个通道求解同一个稀疏线性系统，得到融合结果。
●
输出：普通 copy-paste 结果、Poisson seamless cloning 结果、边界局部放大图。
实验 C：Core Reproduction: Mixed Gradients
●
仍使用实验 B 的三张图。
●
复现论文 mixing gradients：对每条边和每个通道，选择 source 与 target 中绝对值更大的梯度作为 guidance field。
●
输出：copy-paste、source-gradient Poisson、mixed-gradient Poisson 三种结果；至少给出两个局部放大区域。
●
分析 mixed gradients 对目标图纹理、源图边缘和边界自然度的影响。
实验 D：Analysis Extension: Failure Cases
●
本实验是分析扩展，不是论文原实验。
●
案例 1：将 source 图像亮度乘以 1.8 后再进行 seamless cloning，并与原始结果对比。
●
案例 2：将 mask 先膨胀 25 个像素后再进行 seamless cloning，并与原始 mask 结果对比。
●
输出两个失败案例的结果图和局部放大图，解释亮度差异、边界选择和梯度场冲突为什么会导致不自然结果。
五、实现要求
1
主结果必须来自自己构建的 Poisson 方程和线性系统。可以使用 NumPy/SciPy 求解稀疏线性系统；禁止直接调
用 OpenCV seamlessClone 或其他现成 Poisson blending 函数作为主结果。
2
mask 内每个像素对应一个未知量。请建立二维像素坐标到线性系统 index 的映射，并使用稀疏矩阵存储系数。
3
RGB 图像需逐通道求解。矩阵 A 对三个通道相同，右端项 b 不同。
4
报告中必须包含方程、边界条件、矩阵规模、非零元素数量、求解器名称和运行时间。
5
可以使用生成式模型辅助理解、写作或代码调试，但需在报告中说明使用方式；图像编辑模型结果不能替代
上述实验。
六、提交内容
1
实验报告 PDF：建议 7-10 页。鼓励使用 LaTeX 排版，鼓励使用英文写作；中文或英文均可。
2
源代码：包含清晰入口文件，可按 README 步骤复现实验结果。建议目录包含 src/、results/、report/。
3
结果图像：报告中的所有结果图应保存到 results/，并能由代码生成。
4
README：说明依赖、运行命令、输出位置、求解器和外部工具使用情况。
